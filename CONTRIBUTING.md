# Contributing

This is a learning and portfolio project maintained by Rushikesh Deshmukh.

1. Create a branch for each focused change.
2. Run `./mvnw clean test` before opening a pull request.
3. Do not commit credentials, `.env` files, Terraform state, or generated build output.
4. Use clear, conventional commit messages such as `feat:`, `fix:`, `docs:`, or `chore:`.
